# Pink Pong 🩷
### *A Pong for the girlies!*

Pink-Pong is my cute take on the classic Pong game, now in shades of pink with retro pixel art and fun sounds! Unlike many small web games, the project keeps **HTML, CSS, and JavaScript completely separated** for better structure and readability.  

## Features
- 🎮 **Game Modes:** PVP and PVE
- 🌗 **Themes:** Light and Dark mode
- 🚀 **Dynamic Ball:** Ball speeds up over time if no one scores
- ⚡ **Smart Ball Physics:** The ball bounces at different angles depending on where it hits the paddle, making gameplay more dynamic and challenging.
- 🔊 **Retro Sounds:** Bounces, scores, and win effects made with Chiptone by SFBGames
- 🎨 **Pixel Art:** All graphics created by me
- 🛠 **Clean Code Structure:** HTML, CSS, and JS are separated

## How to Play
- **Move Paddle:** Arrow keys ↑↓ or W/S
- **Goal:** Hit the ball and score points

## Technologies
- HTML / CSS / JavaScript
- [Chiptone by SFBGames](https://sfbgames.itch.io/chiptone)
- Aseprite
